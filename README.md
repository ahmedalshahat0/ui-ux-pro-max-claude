## 🎯 What is this?

**UI/UX Pro Max — Claude.ai Edition** is a modified and streamlined distribution of the original **UI/UX Pro Max** project, adapted specifically for **Claude.ai Skills**.

The goal is simple:

> **Give Claude powerful UI/UX design intelligence in a package that can be uploaded directly to Claude.ai.**

This edition removes unnecessary development and platform-specific packaging from the broader upstream project and focuses on the files required for the Claude.ai Skill experience.

---

## 🚀 Why this edition exists

The original UI/UX Pro Max project supports a broader development ecosystem.

Claude.ai Skills have different packaging requirements.

This edition bridges that gap by providing a **pre-packaged, Claude.ai-ready ZIP**.

You do not need to:

- Clone the repository
- Install dependencies
- Run CLI commands
- Move files manually
- Rebuild the package
- Create your own ZIP
- Deal with nested ZIP files

### Just download the package and upload it.

## 📦 Installation

### Claude.ai

1. Go to the **Releases** section of this repository.
2. Download the latest `ui-ux-pro-max-claude-ai-*.zip` package.
3. **Do not extract the ZIP.**
4. Open Claude.ai and go to **Settings → Skills**.
5. Upload the downloaded ZIP.
6. Start using the skill.

> **The ZIP downloaded from this repository is already the final Claude.ai Skill package.**

No extraction.  
No modification.  
No additional setup.

## 🔍 What makes it different?

### Context before aesthetics

Design recommendations should reflect the product, audience, content, and interaction model — not just current visual trends.

### Systems over isolated screens

Typography, spacing, color, components, states, interactions, and responsive behavior should work together as one coherent system.

### Accessibility built in

The skill considers contrast, focus states, readable typography, semantic controls, responsive behavior, and reduced-motion requirements.

### Avoiding generic AI aesthetics

The goal is not to blindly generate:

- Neon gradients
- Excessive glassmorphism
- Giant rounded cards
- Generic dashboard layouts
- Random decorative effects

Instead, visual decisions should be driven by product context.
