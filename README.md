## Overview

This repository provides a Claude.ai-focused distribution of the open-source UI/UX Pro Max design intelligence project.

Use it when designing, building, reviewing, or fixing interfaces. It covers visual direction, layout, typography, color, interaction, accessibility, responsive behavior, charts, design systems, and stack-specific implementation.

> **This is an independent Claude.ai distribution/adaptation. It is not the upstream UI/UX Pro Max repository.**

## What it includes

- **79 searchable UI styles** (50 active)
- **192 product palettes and reasoning profiles**
- **74 font pairings**
- **119 UX guidelines**
- **105 icon references**
- **17 GSAP presets**
- **25 chart types**
- **22 technology stacks**

## Install in Claude.ai

1. Open the **Releases** section.
2. Download the latest Claude.ai Skill ZIP.
3. Open Claude.ai's Skills/settings interface.
4. Upload the ZIP directly as a Skill.
5. Start designing.

**No extraction or additional setup is required.**
