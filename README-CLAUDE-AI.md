# UI/UX Pro Max — Claude.ai Skill Package

This package is adapted from UI/UX Pro Max for upload through Claude.ai Skills.

- The original multi-skill/plugin repository was reduced to the core `ui-ux-pro-max` skill.
- Bundled CSV databases, references, and Python search scripts are preserved.
- Claude plugin-specific `${CLAUDE_PLUGIN_ROOT}` paths were replaced with local `scripts/search.py` paths.
- This package intentionally excludes the Claude Code plugin/marketplace metadata and unrelated companion skills.
